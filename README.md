# GitHub for Teams: The Complete Guide

A free, 189-page PDF guide to Git and GitHub. It starts from your very first repository and goes all the way to running a real project with your friends: branching, pull requests, code review, rebasing, fixing mistakes, GitHub Actions, security and releasing version 1.0.

### 📘 [Read or download the PDF](GitHub-for-Teams-Advanced-Guide.pdf)

GitHub opens the PDF in its viewer. Use the download button at the top right to save it.

## Who it's for

- **Complete beginners.** Part I starts from zero: what Git and GitHub are, creating an account, your first repository, the everyday commands, a tour of the website and writing in Markdown.
- **People who already push their own projects** and now want to work with others. Parts II to VII cover what changes when three or four people share the same code.
- **Teams starting a project.** Part IX is a step-by-step playbook from the first meeting to the v1.0 release, plus troubleshooting, a cheat sheet and practice drills.

## How it explains things

- **"At a glance" cards** for 97 features, each answering five questions: *What is it? Why use it? How does it work? When should I use it?* and a short *Example* scenario.
- **"What each line does" boxes** under every command block, explaining each line in plain words.
- **"In plain English" boxes** that explain hard ideas with everyday comparisons.
- **Diagrams** of how commits, branches, merges and forks fit together.
- A **glossary** of 74 terms, so no word is left unexplained.

The examples follow three friends, Alice, Bob and Chen, building a project together.

## Versions

Written for Git 2.40 or newer (tested against Git 2.55), the GitHub CLI and GitHub.com as of October 2026. GitHub moves buttons around from time to time; if a setting isn't where the guide says, use the search box on the settings page or check [docs.github.com](https://docs.github.com).
